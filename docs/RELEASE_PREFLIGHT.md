## Forward migration prepared — not applied

Generated by the Supabase CLI as:

`supabase/migrations/20261005182200_advance_a2p_policy_disclosure.sql`

The migration is intentionally data-only and forward-only. It:

1. locks and validates the exact expected `2026-09-29-separate-sms` row;
2. stops if its templates, disclosure body, dates, or current status changed unexpectedly;
3. stops if `2026-10-05-policy-clarifications` already exists;
4. changes only the old row's `is_current` flag to false;
5. inserts the new current row with the same checkbox templates/disclosure body and October 5 Privacy/Terms dates;
6. does not alter schema, RLS, ownership, intake records, consent events, suppressions, senders, or messaging configuration.

Historical consent events, if any exist by release time, remain immutable and continue to reference their original disclosure version.
